# {系统名} — 系统级技术标准

> 本文件为**{系统名}系统**的**固化配置与定义**类技术标准，沉淀本系统采用的、跨模块统一的技术选型、规范约定与架构基线：

> 本文件是系统级技术标准**唯一权威源**：模块级 `tech/modules/*/03-*-技术规格.md` 与 `04-*-数据模型.md` 不做架构设计，仅在此引用（见其「0. 架构约束引用」）。

> 产品侧通用规则见项目级 `通用异常处理.md` / `通用校验规则.md`（角色/权限见 `系统要求规范.md`、UI 标准见 `系统交互规范.md`、术语见 `项目级产品摘要.md`）。本文件聚焦**本系统**的技术实现约束；涉及技术规则的约定统一在系统级技术标准 / 技术规范中落地，**不设项目级技术通用规则**。
