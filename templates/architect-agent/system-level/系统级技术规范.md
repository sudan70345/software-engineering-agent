## 3. API 路由前缀

> 本系统所有接口的统一路由前缀约定，模块级 03 接口路径均以此为基础拼接。

| 范围 | 前缀 | 说明 |
|------|------|------|
| 全局前缀 | {如 /api/v1} | 版本化统一前缀 |
| 鉴权接口 | {如 /api/v1/auth/**} | 登录/登出/刷新 token |
| 业务模块 | {如 /api/v1/{module}/**} | 按模块分域，{module} 取模块英文名 kebab-case |
| 管理后台 | {如 /api/v1/admin/**} | 后台管理接口，需管理员权限 |

**约定**：
- 路径命名统一 kebab-case（如 `/api/v1/order_list` → `/api/v1/order-list`）
- 资源名用复数（如 `/orders`、`/orders/{id}`）
- 版本号出现在前缀中（如 `/api/v1`），大版本升级才新增 `/api/v2`
