## 3. 页面总览
- 页面总数: N（主页面 M / 辅助页面 K）
- **页面两类**：
  - **主页面 页面[N]**：承载核心功能的完整页面（如首页、列表、详情、创建页）。
  - **辅助页面 页面[N-A]**：从属某主页面、承载**独立功能组件**的复杂弹窗/抽屉（如「创建订单弹窗」有独立表单+校验+提交），编号为「所属主页面编号 + 字母后缀」（页面[2-A]、页面[2-B]），并记「所属主页面」。
  - ⚠️ **简单弹窗不单列**：操作提醒、结果反馈、确认框（Toast / 成功提示 / 删除确认等，无独立表单与业务处理）**不作为辅助页面**，在其所属主页面的功能组件/页面状态变体中一句话描述即可。判定基准：**该弹窗是否承载独立的功能组件（有自己的输入表单 / 校验 / 提交 / 业务处理）**——有则辅助页面，无则内联。
  - 全局弹窗（不依赖单一主页面，如全局通知中心）当作独立主页面[N]（全局），不挂辅助。
