## 3. 布局结构

### 3.1 整体布局框架

```
┌─────────────────────────────────────┐
│     顶部固定导航栏 (高度60px)        │ ← 固定定位，不滚动
├─────────────────────────────────────┤
│   左侧边栏       │   主内容区域      │
│   (宽度200px)    │   (自适应宽度)     │
│   固定定位       │   可滚动           │ ← 区域关系
│                  │                    │
└─────────────────┴────────────────────┘
```

### 3.2 区域详细定义

| 区域名 | 位置 | 尺寸 | 定位方式 | 可滚动 | 内容摘要 |
|--------|------|------|---------|-------|---------|
| 顶部导航栏 | 顶部 | 宽100%，高60px | 固定定位 | 否 | Logo、搜索框、用户信息 |
| 主内容区域 | 右侧 | 宽100%-200px，高自适应 | 相对定位 | 是 | 表单、列表、图表等 |

**坐标提示**：
