## 3. 布局结构

### 3.1 整体布局框架

```
┌─────────────────────────────────────┐
│   顶部固定导航栏（固定高度档位）       │ ← 固定定位，不滚动
├─────────────────────────────────────┤
│   左侧边栏       │   主内容区域      │
│  （固定宽度档位） │  （自适应宽度）    │
│   固定定位       │   可滚动           │ ← 区域关系
│                  │                    │
└─────────────────┴────────────────────┘
```

### 3.2 区域详细定义

| 区域名 | 位置 | 尺寸语义 | 定位方式 | 可滚动 | 内容摘要 |
|--------|------|---------|---------|-------|---------|
| 顶部导航栏 | 顶部 | 固定高度（`navigation_bar_height`） | 固定定位 | 否 | Logo、搜索框、用户信息 |
| 主内容区域 | 右侧 | 自适应（视口宽 − 侧栏宽） | 相对定位 | 是 | 表单、列表、图表等 |

> ⚠️ **「尺寸语义」列只写档位语义名**（固定档位 / 自适应），令牌取值见 `界面设计要素.md`「布局与尺寸档位」；**本节不写坐标**——坐标由原型阶段按本表语义推导。
