## 1. 按钮规范

### 1.1 按钮状态

| 状态 | 触发条件 | 交互行为 | 视觉令牌（见界面设计要素.md） |
|------|---------|---------|------------------------------|
| 正常态（Normal） | 默认状态 | 可点击 | 主按钮样式（primary） |
| 悬停态（Hover） | 鼠标悬停 | 光标变为手型，背景轻微加深 | primary 加深一档 |
| 点击态（Active） | 鼠标按下 | 视觉反馈 | primary 加深两档 |
| 禁用态（Disabled） | 条件不满足 | 不可点击 | disabled 令牌 |
| 加载态（Loading） | 请求进行中 | 禁用点击，按钮内显示加载动画 | 保持原背景色 |

> 具体颜色值不在此定义，由 `界面设计要素.md`「色板」的 `primary` / `disabled` 令牌提供。

### 1.2 按钮层级

| 层级 | 使用场景 | 规则 | 视觉令牌 |
|------|---------|------|---------|
| 主按钮（Primary） | 页面核心操作 | 一个页面最多 1 个 | primary |
| 次按钮（Default） | 次要操作 | 无数量限制 | 描边/中性样式 |
| 危险按钮（Danger） | 危险操作（删除、禁用） | 需配合二次确认 | danger |
| 文字按钮（Text） | 辅助操作（取消、关闭） | 用于不重要的操作 | text_link |

**使用示例**：
- 「提交订单」页面：主按钮「提交」，次按钮「保存草稿」，文字按钮「取消」
- 「删除确认」弹窗：危险按钮「删除」，次按钮「取消」

### 1.3 按钮尺寸

| 尺寸 | 使用场景 | 视觉令牌（见界面设计要素.md「dimensions」） |
|------|---------|--------------------------------------------|
| 大（Large） | 页面主操作 | button_large |
| 中（Default） | 常规操作 | button_medium |
| 小（Small） | 表格内操作、密集布局 | button_small |

## 2. 弹窗规范

### 2.1 弹窗类型

| 类型 | 使用场景 | 组成元素 | 视觉令牌 |
|------|---------|---------|---------|
| 确认弹窗（Confirm） | 二次确认（删除、提交） | 标题 + 内容 + 取消/确认按钮 | modal 圆角/阴影 |
| 表单弹窗（Modal） | 表单输入（创建、编辑） | 标题 + 关闭按钮 + 表单 + 取消/确认按钮 | modal |
| 提示弹窗（Alert） | 信息提示 | 标题 + 内容 + 确认按钮 | modal |
| 抽屉（Drawer） | 详情查看、多步骤表单 | 标题 + 关闭按钮 + 内容区 + 操作按钮 | modal |

> 各类型的具体宽度等像素值不在此定义，绘制时按内容量在原型阶段确定（参考 `界面设计要素.md`「border_radius」的 `modal` 与「shadows」的 `modal`）。

### 2.2 弹窗交互

| 交互元素 | 行为 | 规则 |
|---------|------|------|
| 遮罩（Mask） | 点击遮罩 | 确认弹窗：可关闭；表单弹窗：不可关闭（防止误操作） |
| 关闭按钮（✕） | 点击关闭 | 等同于「取消」操作 |
| ESC 键 | 按 ESC | 关闭弹窗（等同于「取消」） |
| 确认按钮 | 点击确认 | 验证表单 → 成功关闭 / 失败提示 |
| 取消按钮 | 点击取消 | 直接关闭，不保存 |

### 2.3 弹窗布局

```
┌─────────────────────────────────────┐
│  标题                        ✕     │ ← 标题栏
├─────────────────────────────────────┤
│                                      │
│  内容区域                            │ ← 内容区
│  （表单 / 文本 / 列表）             │
│                                      │
├─────────────────────────────────────┤
│              [取消]  [确定]          │ ← 操作栏（右对齐）
└─────────────────────────────────────┘
```

**布局规则**：
- 弹窗居中显示
- 按钮间距与操作栏内边距遵循 `界面设计要素.md`「间距体系」的 `element_gap` 与 `lg`
- 标题/内容/按钮的字号遵循 `界面设计要素.md`「字体层级」

## 3. 分页规范

### 3.1 分页组件

| 元素 | 位置 | 说明 |
|------|------|------|
| 总条数 | 左侧 | 「共 156 条」 |
| 每页条数选择器 | 左侧 | 「10 / 20 / 50 / 100 条/页」，默认 20 |
| 页码 | 右侧 | 显示当前页 + 前后各 2 页 + 首尾页 |
| 上一页/下一页 | 右侧 | 箭头按钮 |
| 跳转输入框 | 右侧 | 「跳至 [ ] 页」 |

### 3.2 分页位置

- **表格分页**：表格底部右侧
- **列表分页**：列表底部右侧
- **卡片分页**：卡片区域底部居中

### 3.3 分页交互

| 操作 | 行为 |
|------|------|
| 点击页码 | 跳转到该页，刷新数据 |
| 点击上一页/下一页 | 跳转到上/下一页 |
| 修改每页条数 | 跳转到第 1 页，刷新数据 |
| 输入页码 + 回车 | 跳转到指定页 |

## 4. 表格规范

### 4.1 表格样式

| 元素 | 样式语义 | 视觉令牌（见界面设计要素.md） |
|------|---------|------------------------------|
| 表头 | 浅灰背景 + 粗体文字 | surface_secondary + 粗体 |
| 斑马纹 | 奇数行白、偶数行浅灰 | 交替 surface / surface_secondary |
| 悬停态 | 行悬停时背景变浅蓝 | primary 浅一档 |
| 边框 | 横向分隔线 | divider |

### 4.2 表格列

| 列类型 | 位置 | 说明 |
|--------|------|------|
| 复选框列 | 最左侧 | 多选时显示 |
| 序号列 | 复选框后 | 显示行号 |
| 数据列 | 中间 | 根据内容调整 |
| 操作列 | 最右侧 | 操作按钮 |

### 4.3 操作列

| 元素 | 样式语义 | 视觉令牌 |
|------|---------|---------|
| 文字按钮 | 蓝色文字，无背景 | text_link |
| 分隔符 | 竖线「|」 | divider |
| 更多按钮 | 「...」或「更多」 | 展开下拉菜单 |

**示例**：`编辑 | 删除 | 更多`

### 4.4 表格状态

| 状态 | 展示 | 引用 |
|------|------|------|
| 空态 | 「暂无数据」+ 占位图 | 见 `通用异常处理.md` §2.1 |
| 加载中 | Loading 动画 | 见 `通用异常处理.md` §2.2 |
| 加载失败 | 「加载失败」+ 重试按钮 | 见 `通用异常处理.md` §2.3 |

## 5. 表单规范

### 5.1 表单布局

| 布局方式 | 使用场景 | 视觉令牌（见界面设计要素.md） |
|---------|---------|------------------------------|
| 水平布局 | 简单表单（≤5 个字段） | 标签右对齐 |
| 垂直布局 | 复杂表单（>5 个字段） | 标签左对齐 |
| 行内布局 | 搜索框、筛选器 | 标签与字段同行 |

### 5.2 表单字段

| 字段类型 | 说明 | 视觉令牌 |
|---------|------|---------|
| 短文本（姓名、账号） | 避免过宽 | input 高度 |
| 长文本（地址、描述） | 可自适应 | input |
| 数字（年龄、数量） | 居左对齐 | input |
| 日期选择器 | 固定宽度 | input |
| 下拉选择器 | 根据内容调整 | input |
| 多行文本 | 高度 3-5 行 | input |

> 字段具体宽度/高度像素值以 `界面设计要素.md`「dimensions」的 `input_height` 等令牌为准，本文档不写 px。

### 5.3 表单交互

| 元素 | 行为 | 引用 |
|------|------|------|
| 必填标识 | 红色星号「*」，标签前 | danger 令牌 |
| 字段提示 | 占位符或字段下方灰色提示 | text_tertiary |
| 错误提示 | 字段下方红色文字 + 输入框红色边框 | danger |
| 成功提示 | Toast「保存成功」 | 见 `通用异常处理.md` §4.1 |

## 7. 使用指南

### 7.1 模块文档中如何引用

在模块的 `02-模块-UI交互规格.md` 中：

```markdown
## 5. 关键交互行为

| 触发元素 | 交互类型 | 目标/反馈 | 说明 |
|---------|--------|----------|------|
| 提交按钮 | click | 成功→Toast提示 | 按钮状态详见 ../../系统交互规范.md §1.1 |
| 删除按钮 | click | 二次确认弹窗 | 弹窗规范详见 ../../系统交互规范.md §2 |
```

### 7.2 何时需要在模块中单独描述

不需要重复：
- 按钮的通用状态（正常/悬停/禁用/加载）
- 弹窗的通用交互（遮罩/ESC/关闭）
- 分页、表格、表单的通用规范

需要单独描述：
- 模块特有交互（如「拖拽排序」「右键菜单」「双击编辑」）
- 复杂的多步骤交互（如「引导流程」「向导式表单」）
- 特殊的视觉反馈（如「实时预览」「动画效果」）
